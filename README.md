# Restaurant Page
This is a demo restaurant page that is dynamically rendered with javascript.

## *Insights*
I hit a wall working on this and realised the limits of abilities making a UI, it was interesting to know just how far I have come though, rendering an entire webpage with javascript, c'mon isn't that just cool? It gets you wondering just what more javascript it capable of.

# Conclusions
This project emphasizes DOM manipulation and goes a step further to demonstrate the rendering of a page with javascript, which is essentially the same thing now that I think about it. It's more like a foreshadow at this point when you think of React I imagine.
